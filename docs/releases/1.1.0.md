# Release 1.1.0

## Highlights

- Expanded every service with a consistent set of business concepts, each with
  an entity, repository, service, controller, request, response, unit test and
  web test.
- Added shared value types for money, percentages and paging.
- Added text, check, duration, date and identifier helpers.
- Fixed three rule defects found by the test suite.

## New concepts by service

### Catalog

Product variants, images, tags, price books, discount rules, bundles,
warranties, supplier contracts, SEO entries and import jobs.

### Inventory

Bin locations, lots, serial numbers, stock alerts, pick lists, putaway tasks,
inventory audits, backorders, transfer lines and safety stock.

### Order

Wishlists, checkout sessions, order notes, shipment tracking, gift cards,
cancellation requests, exchanges, preorders, layaways and order approvals.

### Payment

Payment methods, merchant accounts, gateway transactions, fraud checks,
disputes, currency rates, payout batches, refund lines, card tokens and fees.

### Customer

Contacts, loyalty transactions, customer notes, groups, tags, referrals,
feedback, survey responses, communication preferences and identity documents.

### Shipping

Shipping labels, tracking events, zones, carrier accounts, packaging types,
delivery attempts, dispatches, route plans, freight quotes and customs
documents.

### Notification

Notification preferences, channels, bounced emails, push subscriptions,
event logs, newsletters, announcements, recipient lists, send attempts and
suppressions.

## Fixes

- `AdjustmentService` rejected every non-negative priority and accepted
  negative ones. It now rejects only negative values.
- `ReplenishmentService` returned `Optional.get()` for a missing item and
  raised `NoSuchElementException`. It now raises `NotFoundException`.
- `SupportTicketService` skipped the duplicate-code check. It now rejects a
  duplicate code before writing.

## Shared library

| Type | Purpose |
| --- | --- |
| `Money` | Amount plus currency, safe arithmetic |
| `Percentage` | 0-100 value, fraction and application |
| `PageRequest` | Validated zero-based page request |
| `PageResult` | Page items, total and navigation helpers |
| `Texts` | Truncation, slugs, initials, masking |
| `Checks` | Preconditions with useful messages |
| `Durations` | Human and ISO duration helpers |
| `Dates` | UTC day boundaries and ranges |
| `Ids` | Identifier normalisation and formatting |

## Upgrade notes

No schema migration is required for the new domains in a local H2 run.
Production adds the new tables through versioned migrations. All changes are
additive; the existing endpoints keep their contracts.

## Verification

The full Maven test suite passes. Each new domain has a service test and a
standalone web test. The shared library has 70 tests of its own.
